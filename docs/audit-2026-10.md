## Security

### Verified on the live site (pass)
- **Headers:** CSP, HSTS, `X-Frame-Options: DENY` (it even blocked our own audit iframe), nosniff, Referrer-Policy, Permissions-Policy, COOP. No `x-powered-by`. TLS 1.3.
- **APIs:**
  - wrong HTTP methods → 405
  - bodies over 16KB → 413
  - malformed JSON → 400, with no stack traces leaked
  - cross-origin POSTs → 403 (CSRF), and preflight gets no CORS permission
- **Auth surfaces:** `/api/v1/me`, `/api/v1/admin/*` → 401 when signed out. `/account` and `/admin` redirect to `/login`.
- **Open redirects:** `/auth/callback?next=https://evil…`, `//evil` and `/\evil` are all neutralised.
- **No exposure:** `.env`, `.git`, `package.json`, `supabase/config.toml` and source maps all 404. No secrets in git history. `npm audit`: 0 vulnerabilities.
- **Rate limiting:** blocks after 5 Academy submissions per 10 minutes. Spoofing `x-real-ip`, `x-forwarded-for` or `cf-connecting-ip` does **not** bypass it.
- **No cookies** on public pages.
- **Database:** RLS + column grants + atomic registration, covered by 2 SQL test suites (`npm run check`).

### Found and fixed ✅
| # | Finding | Severity | Fix |
|---|---|---|---|
| S-1 | JSON-LD used `JSON.stringify`. An event description containing `</script>` (entered in the DB) would run as script for every visitor (stored XSS). | High (admin-only input) | `lib/jsonld.ts` escapes `< > & U+2028/9`; test added |
| S-2 | HSTS had `includeSubDomains; preload`. After switch-over this would force HTTPS on HostGator's `mail.slswca.com`/webmail, and preload is very hard to undo. | Medium | Main domain only until DNS and email move |
| S-3 | No rate limit on payment-status lookup (order-id guessing), ticket cancel, or profile updates. | Low | Limits added |

## UI / UX / accessibility

### Found and fixed ✅
| # | Finding | Fix |
|---|---|---|
| U-1 | The nav logo was downloaded at 3840px wide and was the largest element on every page (slowest paint) | Requested at real size; mobile LCP 3.0s → 2.1s |
| U-2 | The Supabase sign-in library (about 90KB) shipped on every page even with sign-in off | Lazy-loaded only when auth is configured |
| U-3 | Placeholders showed wireframe captions ("HERO PHOTO — ATHLETE MID-MOVE") to the public | Production shows a faint brand mark; captions only in dev |
| U-4 | Empty partner tiles ("Energy partner logo") on Home and Partners | Home shows only partners with logos; empty slots on Partners become "Become our energy partner →" links to the CTA |
| U-5 | Tap targets under 44px: text links (25px), logo (32px), footer Privacy (20px), checkboxes (16px) | Hit areas enlarged to 44px without layout change; checkboxes 20px |
| U-6 | Partner logo alt text duplicated the caption (Lighthouse "redundant alt") | Alt is the partner's name, or empty when the caption says it all |
| U-7 | Club chips had a hover effect but weren't links | Hover removed (until club pages exist) |
| U-8 | Contribute let people fill the whole form, then said "not open yet" | Shows "Online giving opens soon" + WhatsApp/Instagram until PayHere is configured |
